# 附录一　把容易混淆的词放在一起

这些解释供阅读时回查。不同语言、软件与专业传统的用词不完全重合，遇到具体工具仍需看其文档。

| 词语 | 本书中的含义 | 容易混淆的对象 |
|---|---|---|
| 字符 Character | 文字系统中的抽象单位，在编码系统中有相应表示 | 字符不是屏幕上一幅固定图像 |
| 字形 Glyph | 字体里可供排印的具体形态 | 一个字符不保证只有一种字形 |
| 字体 Typeface | 一套共享设计规则的字形系统；日常也泛指字体文件 | 家族、样式与文件需要结合语境区分 |
| 字体文件 Font file | 供软件使用的字体数据资源 | 一个文件不一定只有一种静态样式 |
| 字族 Family | 设计上有关联的一组样式 | 相似外观不自动构成同一家族 |
| 字重 Weight | 家族内笔画重量的设计变化 | 人工描边不等于制作好一款粗体 |
| 宽度 Width | 字体设计中的宽窄变化 | 压扁轮廓不等于设计好窄体 |
| 斜体 Italic | 具有专门设计的倾斜样式，常伴随结构变化 | 不一定等同于整体机械倾斜 |
| 衬线 Serif | 某些笔画末端的附加形态 | 中文宋体与拉丁衬线体不能简单互译历史 |
| 无衬线 Sans serif | 不以衬线作为主要末端特征的拉丁字体类别 | 仍然包含多种结构与笔画变化 |
| 字号 Point size | 字体排印尺寸的设定 | 同字号不保证可见字形同样大 |
| em | 与字号相关的相对度量单位 | 不等于某一个字的实际黑色宽度 |
| 字面 | 中文讨论中常指字形可见部分及其占位关系 | 需说明讨论的是宽、高还是整体视觉大小 |
| 中宫 | 观察汉字内部结构收放的一种描述 | 不宜假装存在跨所有字体的统一百分比 |
| 重心 | 字形在视觉上重量集中的位置 | 不等同于所有情况下的几何质心 |
| 基线 Baseline | 排版中安置字形的重要参考线 | 不是每个字形的最低像素边缘 |
| x 字高 | 拉丁小写中以 x 等字形代表的主体高度 | 与大写高度、字号不同 |
| 升部、降部 | 某些小写字母超出主体高度或伸到基线下方的部分 | 与行距的分配不是同一件事 |
| 字腔 Counter | 字形内部封闭或部分开放的空白 | 空间也参与字形识别与节奏 |
| 边距 Sidebearing | 字形两侧的基础留白或度量关系 | 不是 kerning 的同义词 |
| 字偶调整 Kerning | 对特定字形组合进行定位或间距补偿 | 不负责统一改变整段文字的松紧 |
| Tracking | 对一段或一串文字进行整体字距调整 | 不能代替每个组合的局部判断 |
| 行距 | 相邻行的垂直节奏，具体实现依软件而异 | 设定行高与可见空白不一定相等 |
| 视觉越界 Overshoot | 曲线等部分相对参考线的视觉修正 | 没有适用所有字体的固定幅度 |
| 可变字体 | 可通过一个或多个设计轴在支持的软件中选取实例的字体 | 不保证所有轴、语言或应用都受支持 |
| OpenType | 含字形、映射、度量与排版数据等的字体技术规范 | 文件扩展名无法单独说明所有轮廓与功能 |
| Shaping | 根据文字、语言、字体规则等确定字形和位置的过程 | 不只是把字符逐个画出来 |
| 字体回退 | 选定字体无法覆盖字符等情形下使用其他字体 | 可能造成字重、基线和风格突然变化 |
| 字符覆盖 | 字体支持哪些编码字符的范围 | 字符多不自动代表地区字形或排版正确 |
| 子集化 | 按需要保留字体的部分内容 | 会改变覆盖范围，许可与重命名要求仍须核对 |

进一步核对术语，可阅读 [FontForge 术语表](https://fontforge.org/docs/glossary.html)、[Microsoft OpenType 规范](https://learn.microsoft.com/en-us/typography/opentype/spec/)与 [Unicode 标准导论](https://www.unicode.org/standard/standard.html)。本表是入门解释，不替代规范中精确的数据结构定义。
